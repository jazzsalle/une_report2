- 버전: v1.0 (2026-08-19)
- 목적: **동작하는 POC**를 만들어 개발팀에 인계한다. 보안·암호화·멀티테넌트·감사·멱등성은 범위 밖.

## 1. 시스템 구성

```
apps/poc/
  server/   Express (:3100)  — UNI 프록시, rhwp 엔진, JSON 저장소
  web/      Vite+React (:5300) — 계획서 도구 + 상황일지 도구 (한 셸, 두 앱)
  data/     *.json (컬렉션), files/ (업로드·생성 HWPX)
  docs/     이 문서들
```

한 명령으로 뜬다: `pnpm --filter @une/poc dev`.

## 2. 재난안전계획서 생성 도구 (PLAN)

2차년도 화면설계서(V0.2.6)의 흐름을 따른다: **문서 저장 → 기준정보 준비 → 목차 생성/편집 → 초안 생성(목차별 진행 확인) → 편집 → 내보내기**.

화면 스타일(2026-08-21): KRDS v1.0.0 토큰 기반 업무시스템형 골격 — 상단 헤더+GNB(`AppHeader`), 문서 작업 화면은 단계 파이프라인 칩 + 우측 "생성 기준"·"연동 상태" 레일. 시안은 `design_handoff_krds_uiux/poc-plan/`, 구현은 `apps/poc/web/src/krds.{css,tsx}`. 상단 헤더는 2026-08-22에 Figma "Header" 컴포넌트(50px, `#222931`, 좌 로고 심볼+서비스명 · GNB · 우 알림/설정 아이콘·날씨·사용자 선택·"○○님 환영합니다")로 교체 — 심볼·아이콘은 피그마 벡터를 SVG로 변환해 `web/public/hdr/`에 둠(알림·설정·날씨는 목업). 상황일지(/sit)·홈·모바일도 같은 날 같은 스타일로 맞춤 — 상황일지는 공통 부품 `ui.tsx`를 KRDS 클래스로 갈아끼우는 방식(셸은 상단 헤더 + LNB 띠 + 현재 훈련상황 띠).

### PLAN-01 템플릿 스타일 분석 모듈 (신규, 사용자 요구 ②)

| 항목 | 내용 |
|---|---|
| 입력 | HWPX 파일 업로드 (`templete/*.hwpx` 6종으로 검증) |
| 처리 | rhwp WASM(`@rhwp/core`)으로 파싱 → 스타일 목록(`getStyleList`), 개요번호 형식(`getNumberingList` → `levelFormats` 예: `^1.`,`^2.`,`^3)`), 문단별 글꼴·크기·굵기·정렬·들여쓰기(`getCharPropertiesAt`, `getParaPropertiesAt`), 문단 텍스트 |
| 출력 | **템플릿 프로파일 JSON**: `{ templateId, name, styles[{id,name}], numbering[{id,levelFormats}], levels[{level, styleId, styleName, bullet, fontFamily, fontSizePt, bold, indent, charShapeId, paraShapeId, prefix}], layout{sampleStart,sampleEnd}, tableStyle{table, header, firstCol, body, colWidths, caption}, sampleParagraphs[] }`. **표 스타일**(2026-08-21): 견본 표(행·열 ≥2, 병합 없음, 견본 구간 안 우선)의 머리행·첫 열·본문 셀 배경/테두리/여백/글자·문단 모양 ID와 열 너비를 읽는다. 없으면 `null` |
| 활용 | (a) LLM 프롬프트에 "1수준 □ 16pt 굵게, 2수준 ㅇ 15pt, 3수준 - 15pt, 4수준 * 12pt" 규칙 주입 (b) HWPX 내보내기 때 heading level → `styleId` `applyStyle` (c) 웹 렌더 CSS에 글꼴·크기 반영 |
| 검증 | `문서 템플릿_01.hwpx`에서 26 스타일·개요 4수준·글자크기 16/15/15/12pt 인식 (실측 2026-08-19) |
| 견본 구간 | 첫 기호 문단 ~ 마지막 견본 요소(기호 문단·`< 표 제목 >`·그 다음 표). 견본 바로 뒤의 **빈 표**도 견본으로 본다(`AI 행정문서 템플릿`의 꼬리 빈 표가 내보낸 문서 끝에 남던 문제, 2026-08-21). 프로파일에 `version`을 두고 규칙이 바뀌면 서버 기동 시 자동 재분석 |
| 원본 미리보기 | 템플릿 화면 [원본 미리보기] = rhwp `renderPageSvg` 쪽 이미지(모달 폭에 맞춰 축소). 2026-08-21 HTML 렌더를 SVG로 교체 — 제목 표·기호·글꼴·표·하단 박스가 원본과 같게 보임. 한글→PDF 스냅샷은 불필요 |

### PLAN-04 초안 생성 스트리밍 (SCR-CADM-402004/005, 101004)

| 항목 | 내용 |
|---|---|
| 방식 | 목차 항목별로 서버가 T3Q/UNI 응답을 웹에 SSE로 중계. 항목별 상태: `-`/대기/진행중/취소대기/취소/완료/오류 (화면설계서 어휘). **일괄 생성은 동시 3절 병렬**(2026-08-21, `PlanEditor.tsx` `CONCURRENCY`) — T3Q는 절 하나를 통째로 15~20초 뒤 돌려주므로 순차(11절 3~4분)보다 약 3배 단축. 절별 스트림·취소 플래그가 독립이라 서버 변경 없음. T3Q 동시 호출 제한이 확인되면 값만 낮춘다 |
