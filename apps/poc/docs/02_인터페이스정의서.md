# UNE 재난안전 AI 문서 POC — 인터페이스 정의서

- 버전: v1.0 (2026-08-19)
- 서버: `http://127.0.0.1:3100`, 웹 dev 서버가 `/api`를 프록시한다. 응답은 JSON, 오류는 `{ error: string }` + 4xx/5xx.
- 스트리밍은 **SSE** (`text/event-stream`), 프레임 `event:`/`data:`.
- 저장 형태: `apps/poc/data/<collection>.json` (배열). 모든 행은 `id, createdAt, updatedAt`.

## A. 외부 인터페이스

### A-1. UNI RAG API (T3Q 대체 겸용) — `UNI_BASE_URL=http://10.20.10.101:8088`

| 용도 | 메서드/경로 | 요청 | 응답 | 실측 |
|---|---|---|---|---|
| 로그인 | `POST /auth/login` | `{account, password}` | `{token, user{user_id,user_email,user_name,...}}` | 200 |
| 채팅 스트림 (목차·초안·문장 수정·일지 서술) | `POST /chat/` | `{query, stream:true, top_k, model_key}` | SSE `data: "토큰"` …, 끝에 `data: {"__sources__":[{filename,score,text,doc_id}]}` | 첫 토큰 ~5s, 63청크/7s |
| SOP JSON | `POST /chat/json` | `{query, top_k}` | SSE, 각 `data:`가 노드 객체 (`compnSn`(number)·`compnTyCode`·`compnSj`·`compnAttrbSaveParamsList`·`endCompns`·`receiveOrgnztSns`) | CC-410 3표본 |
| 모델 목록 | `GET /models/` | – | `{models[{key,label,available}]}` — `exaone-4.5`, `qwen3.6-35b` | 200 |

| 문서 목록 | `GET /documents/?page&page_size&q` | – | `{documents[{doc_id,filename,status("완료"),progress}], total}` | 200, 20,671건 |

- 인증 헤더 `Authorization: Bearer <token>`. 401이면 재로그인 1회.
- **폴백**: `UNI_MOCK=1` 또는 접속/타임아웃 실패 시 `server/src/mock/*.md|json` 재생.
- 주소 `:3101`은 웹 UI다. API 아님.

## D. LLM 프롬프트 계약 (server/src/llm.ts)

| 함수 | 입력 | 기대 출력 | 정규화 |
|---|---|---|---|
| `generateToc(ctx, styleRule)` | 기준정보 | JSON `[{no,title,children}]` 2수준 이내 6~10항목 | 코드펜스 제거 → JSON.parse 실패 시 줄 단위 파싱 폴백 |
| `draftSection(ctx, toc, node, styleRule)` (stream) | 항목 | 마크다운 본문 (해당 절만, heading 없이 시작) | 코드펜스 제거, `#` 레벨을 depth+1로 재매핑 |
| `revisePara(para, prev, next, instruction, styleRule)` | 문단 | 교체 문단 텍스트만 | 따옴표·머리말 제거 |
| `generateSop(exercise, planExcerpt?)` | 훈련상황 | UNI `/chat/json` 노드 배열 | uni-sop-2 매핑, END 합성 |
| `narrate(kind, facts)` | 이벤트 목록 | 서술 문단 | |
| `analyze(board)` | 상황판 요약 | `{suggestion, basis}` 한 줄 | |

T3Q가 열리면 이 여섯 함수 안의 `chatStream/chatText` 호출만 T3Q 어댑터로 바꾼다.
